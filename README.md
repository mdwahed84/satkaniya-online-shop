# সাতকানিয়া অনলাইন শপ

এটি একটি সম্পূর্ণ static, responsive demo e-commerce website।

## চালু করা
`index.html` ব্রাউজারে খুলুন।

## ফ্রি hosting
GitHub Pages বা Cloudflare Pages-এ এই ফোল্ডারটি upload/deploy করা যাবে।

## বর্তমানে কাজ করে
- Responsive homepage
- Search
- Category navigation
- Add to Cart counter
- Cart count localStorage-এ থাকে
- Product cards
- Offers / service sections
- Mobile sidebar
- Footer/contact section

## গুরুত্বপূর্ণ
এটি frontend/demo version। Real order database, admin panel, customer login এবং payment gateway যোগ করতে backend লাগবে।
